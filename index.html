muse-comfy

個人用のツールです。作った本人だけが使います。

プライバシーポリシー

  • このツールは、本人の Google ドライブの決まったフォルダにあるファイルを読み書きするためだけに、Google ドライブへのアクセスを使います。
  • 個人情報やデータを集めたり、第三者に渡したり、売ったりすることはありません。

English

muse-comfy is a personal tool used only by its author.

Privacy policy: It uses Google Drive access only to read and write files in one folder of the author's own Google Drive. It does not collect, share, or sell any personal data.
